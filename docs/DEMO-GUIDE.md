# 投标演示操作手册

## 现场准备

安装Python 3.10+并提前启动一次。无需模型网络、数据库服务或第三方包。双击start-demo.cmd，保留终端窗口；首页显示34笔虚构业务。准备浏览器缩放90%—100%，推荐1366px及以上屏幕。现场演示使用虚构数据，不将结果描述为生产查实率。

## 1. 配置本体（2分钟）

进入“财务本体”，展示四层结构。点击新增实体，编码 `acceptance`、名称“验收记录”、层级“单据与凭证层”；新增属性 `number` / “验收编号” / string / 非必填。保存草稿。

新增关系，编码 `has_acceptance`、名称“关联验收”、起点 event、终点 acceptance。保存。点击检查影响并发布，说明“新增验收语义”，发布。

说明新增实体与关系是在维护统一语义定义；当前实例图算法仍是预设账户关系，新增关系的实例自动抽取与图数据库落地是后续接入工作。

## 2. 执行三维筛查（2分钟）

首页“执行全量筛查”。初始规则得到2条交叉风险、2条单维线索。

| 业务 | 实际计算 | 演示要点 |
|---|---|---|
| DEMO-031 | 68,000支付 / 20,000合同；缺验收；同类金额离群；与另一供应商共用账户 | 三维命中，100分，高风险线索，仍需人工 |
| DEMO-033 | 42,000支付 / 15,000合同；金额离群 | 流程+统计，55分，中风险线索 |
| DEMO-032 | 正常金额，共用账户 | 只有图谱命中，不能直接认定风险 |
| DEMO-034 | 正常金额，缺少验收 | 只有流程命中，应核对原件 |

逐条展开“结构化证据与计算口径”，说明来源字段、参照样本、MAD和阈值。统计样本不足5笔时标记未评估，不伪装为未命中。

## 3. 调参、发布与历史隔离（1分钟）

进入风险模型，把“同类金额稳健离群”阈值从3.5改为100，保存草稿，检查影响并发布，执行新筛查。DEMO-033从双维风险变为单维线索；DEMO-031仍有流程+图谱命中。风险数量随计算改变，不是固定展示。

在风险研判的运行快照中切回原运行，原版本和原证据仍保留。演示结束可重新设置3.5并发布新版本，保留全过程。

## 4. 人工研判与图谱（2分钟）

查看DEMO-031，研判选择人工确认风险，填写“演示审核员”及核对依据后保存。再进入同一记录，选择整改关闭并填写虚构整改记录。演示中明确这是测试操作，不代表真实审批。

查看DEMO-032，确认状态列表没有“人工确认风险”。进入关联图谱，选择DEMO-SHARED-01；从示例远山设备到示例青禾材料查询路径，展示两供应商经账户相连。共用账户可能有委托收款等合理解释，图谱关联本身不是违法证明。

## 5. 导出（1分钟）

在风险研判下载CSV台账，Excel中中文可读；打开研判报告，按Ctrl+P选择“保存为PDF”。JSON归档包含当次配置、业务、计算证据与复核记录。PDF通过浏览器打印生成，本扩展没有原项目的PDF排版引擎。

## 演示结束与备份

Ctrl+C停止服务后复制`.local`目录作备份；再次启动保留配置与结果。如需新的干净演示环境，保留旧数据后使用`python server.py --database .local/new-demo.sqlite3 --port 8766`。不需要删除原数据库。
