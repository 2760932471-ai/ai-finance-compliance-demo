# 投标演示讲解路径 v0.7

## 准备

安装Python3.11+，解压源码后双击Windows `start-demo.cmd`。首次安装依赖需联网，之后结构化合规演示可离线进行。默认不调用外部模型；真实AI审核使用 `python bootstrap.py --live`，需目标电脑Codex登录环境。

## 第一段：本体与模型（约2分钟）

进入“审核中心 → 财务本体”，介绍业务事件、单据凭证、核算科目、主体对象四层。点击实体查看属性；可新增可选属性、关系、分类和来源字段映射。配置保存为草稿，发布时做兼容影响检查。

进入“审核中心 → 交叉核验策略”，将高风险分值从70改成80，保存，填写发布说明并发布。说明阈值为示例业务口径，不宣称已完成生产标定。单维命中不能直接定性，与分数高低无关。

## 第二段：三维互证（约2分钟）

进入“运营中心 → 风险研判”，执行筛查。初始34笔虚构记录中：DEMO-031为三维命中100分，DEMO-033为双维55分，DEMO-032与034为单维待核验，另外30笔未命中。

打开证据明细，逐项展示金额、合同、付款日期、验收标记、同类统计基线、共用账户。统计排除本笔、同单位同类型且至少5个参照样本；少于5个显示未评估。

进入“关联图谱”，选择共用账户查看关联供应商与业务。填写人工研判后导出CSV、HTML与JSON；HTML可打印为PDF。配置和数据变化后应重新筛查，历史快照保留。

## 第三段：与原审核贯通（约2分钟）

进入“开始审核”，上传 `examples/demo-audit-materials.zip`，项目命名为“投标演示·虚构设备采购”。无在线模型时会显示65项待判断，这属于真实技术状态。

点击“纳入风险筛查”，对照原件填写以下虚构事实：

| 字段 | 演示值 |
|---|---|
| 单位 / 供应商 | 示例集团华东分部 / 示例远山设备 |
| 经办人 / 账户 | 演示经办人 / DEMO-SHARED-001 |
| 合同编号 | DEMO-CONTRACT-001 |
| 支付 / 合同金额 | 68000 / 10000 |
| 签约 / 付款日期 | 2026-10-10 / 2026-10-09 |
| 验收事实 | 尚未验收 / 缺少验收凭证 |

选择D001-P1，填写确认人与依据，勾选替换虚构工作数据。保存后重新筛查。此时只有一笔业务，三个流程规则命中仍只算一个维度，结果为“单维待核验”；样本不足的统计项不会伪装为已评估。

从“查看证据 → 原审核证据”跳回原材料页，说明来源、版本、人工确认与原件定位的闭环。需要恢复34笔演示数据时，在风险研判导入 `examples/business-data.json` 并重新筛查，旧运行仍保留。

## 演示表述边界

可以展示已实现的配置、计算、版本、追溯与人工闭环。不可将虚构数据命中比例表述为查实率；不可将代码测试通过表述为98%识别准确率或招标性能验收通过。原AI审核规则仍为T1活动类，跨业务风险模型可另行配置。

## 新增：运营中心 → 风险模型与评测

1. 风险模型：选采购单价异常，调整历史窗口与统计灵敏度，保存草稿并填写说明发布。
2. 基线与效果评测：选择2026-10运行，展开异常样本，展示当前单价、历史中位数、正常区间和基线样本数。
3. 切换月度费用异常增长：选择2026-07至2026-10，展示逐月结果、同比和环比。
4. 切换多指标付款行为异常：真实调用本机 Isolation Forest，展示联合异常得分与训练阈值；单指标偏离不是因果解释。
5. 人工核实标签并导出快照；合成标签的精确率/召回率仅作操作演示。
6. 审核回归评测：保留原已核实反馈的预期结论对比，与统计模型效果评测分开。

## v0.7 产品截图演示

打开 `static/demo.html`（离线可用），左右键/空格翻页，N展示讲稿，E编辑标题与说明，Ctrl+S下载编辑后的HTML。点击截图放大。`static/demo.pdf`适合发送或打印。

建议8—10分钟：材料接入 → 知识切片 → 召回依据 → 财务本体 → 风险模型 → 基线评测 → 供应商联查 → 风险研判 → 证据闭环 → 模型运行保障。

本地真实来源图谱：在关联图谱页导入单独提供的`private-supplier-graph.json`；选择原材料供应商，可查看原运行/证据编号与文本摘要。金额有矛盾，保留未核实，不计入支付金额。演示补充关系与来源材料单独标注；点击“加载投标演示场景”会切换当前图谱，历史修订保留。

投标前在目标电脑运行 `python bootstrap.py --live` 后检测模型环境，并用获授权测试材料验证推理。当前系统通过Codex CLI调用模型服务，不能把“本机CLI已找到”讲成“本地离线大模型已部署”。Jev/StartLux需独立服务与配置，关闭不影响统计计算、切片召回和图谱操作。

开发者重新生成截图稿需安装`fonttools`，运行`python scripts/build_product_demo.py`；它只读取`docs/demo-screenshots/`中的公开演示截图并使用随包附带的授权字体子集。PDF由浏览器打印，纸张使用文档定义的16:9尺寸。
