# SDD-04：可读报告、可解释审核与本机安全

规格日期：2026-10-14。状态：开发前基线已实现并回归，实施与验收见 `SDD-04-IMPLEMENTATION.md`。此次先写规格、接口约束和验收测试，再实现与验证；不追溯改变首版的开发历史。

## 目标与范围

依据比赛通知的业务35分、AI-Coding35分、工程质量30分，增强现有本地单用户T1系统。保留原始ZIP、65条规则、三态判定、人工责任与独立HTML报告。PDF成为默认导出格式；历史HTML报告继续可读。本轮不调用在线模型重审考试材料，不改变历史模型判定，不伪造财务金标。

## 验收标准

| ID | 可验证行为 | 验收方法 |

| REP-01 | 一次导出固化一份结构化快照，PDF/HTML由同一快照生成；之后改判不改变旧报告 | 临时数据库：导出后新增人工复核，旧文件和摘要保持不变 |
| REP-02 | 默认PDF可独立打开、中文可搜索、A4分页、有页码与证据书签；保留HTML和JSON下载 | PDF解析/渲染；HTTP Content-Type、文件头及下载名断言 |
| REP-03 | 概览含结论、规则覆盖、P0、三态、人工确认状态；逐项含规则、事实、依据、来源、缺证、建议 | 65条覆盖及P0汇总测试；真实历史运行导出检查 |
| REP-04 | AI原判与人工决定分别呈现；证据文件/页码、识别来源、不确定区、原始OCR分别标识 | 改判及部分可读材料测试，视觉验收 |

| SEC-01 | 仅允许本机完整Host与同源请求；跨站Fetch Metadata拒绝；写操作必须有会话令牌 | 错误Host/端口、Origin、Sec-Fetch-Site和令牌组合测试 |
| SEC-02 | 请求体有大小、类型、传输方式和对象结构限制；错误不泄露磁盘路径/异常原文 | JSON数组、非JSON、超限、Transfer-Encoding及故障注入测试 |

| ENG-01 | 新模块有清晰职责、可读函数与接口；规格—测试—代码映射及真实失败记录可复核 | 本文件、Schema、测试日志、实施记录、交付包 |

## 数据与API契约

- `POST /api/runs/{id}/report`：JSON对象，可含`format`（`pdf`默认，或`html`），均生成PDF、HTML、JSON。返回`id/run_id/time/verdict/formats/snapshot_sha256`和相对下载URL，不返回本地路径。
- `GET /api/reports/{id}?format=pdf|html|json`：新报告默认PDF，旧报告默认HTML。HTML `preview=1`允许内联；PDF/JSON下载。下载前校验文件摘要。不将HTML改名为PDF。
- 快照`audit-report-v1`包含项目与运行标识、规则版本、原始AI结果、当前有效结果、证据、人工记录、确定性汇总、技术核验及有限执行来源。绝对磁盘路径、密钥、请求令牌不写入可下载快照。
- JSON Schema：`docs/schemas/report-snapshot.schema.json`。运行时做关键不变量检查；Schema和测试共同约束后续兼容。
- PDF使用ReportLab本地排版，显式中文字体，图片仅从校验过的本地材料读取，不抓取外链。解析内容作为文字转义，不作为HTML/命令执行。

## 设计决定与取舍

1. 保留比赛要求的HTML并新增PDF，避免浏览器“打印另存为”依赖操作人员设置。
2. 一份快照供多个渲染器使用，模型输出不参与导出时二次总结，避免报告与界面结论漂移。
3. 可解释性提供可核查的事实、规则、证据和决策来源，不声称展示模型内部思维，也不将程序结构校验包装为业务正确性。
4. 安全控制按本机单用户部署设计。会话令牌防跨站写入，不是企业身份认证；哈希发现意外/单文件篡改，不防具有数据库与文件双重写权限的本机管理员。
5. 上传隔离、ZIP限制、外链阻断和模型工具禁用保留。无绝对提示注入防护承诺；无企业级RBAC/SSO、恶意软件扫描、备份灾备和外部鉴真承诺。

参考：[OWASP文件上传](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html)、[OWASP提示注入防护](https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html)。它们用于设计检查，不等于第三方认证。

## 排版验收反馈（实现后的规格修订，2026-10-14）

首次真实PDF为129页，其中离线HTML资源的长正文占用数十页。为提高可读性，增加REP-06：65条规则的事实、依据和意见保持完整；证据附录展示原件图与明确标注的文字摘录，限制字符数和行数，首尾选取并标注中间省略，未展示的完整提取文字/原始OCR仍保存在同一快照JSON与HTML中。不得把截断摘录冒称全文。PDF书签分为章节、规则和证据两级。此修订先记录再修改渲染器，追加超长文本验收测试。
