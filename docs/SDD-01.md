# SDD-01：合规演示扩展

## 来源与范围

依据需求文件 1.2、1.3、1.4、1.5、1.6 与 2.4，开发可独立运行、可接入原审核系统的演示扩展。新上传包缺少 `outputs/financial-audit` 应用源码，只有 PPT 文件、启动器和不含应用的 Git 对象。因此本仓库不是原 v0.4 的修改版，不包含原有 OCR、65 条规则、StartLux 或 PDF 引擎。原源码到齐后按 docs/INTEGRATION.md 接入。

## 可验证行为

1. 本体分四层，实体、属性、关系、分类、来源字段映射可配置，校验重复编码、属性类型、关系端点。发布前显示相对当前发布版的影响分析；不兼容变更拒绝发布。
2. 风险模型可新增、编辑、启停，规则仅支持白名单操作，不运行任意表达式。每条规则有维度、参数和权重；每个模型配置分级阈值。发布生成不可变配置快照。
3. 流程核验计算合同超付、缺少验收、日期倒置；横向对比使用同业务类型、同单位的其他业务中位数/MAD，样本不足输出未评估；图谱联查从供应商共用收款账户计算关联。
4. 单维命中为“待核验线索”；至少两维命中才进入“交叉风险待研判”；系统不输出违规已查实。人工确认、排除、整改关闭要求姓名和原因；低于两维的线索不能直接标记为已确认风险。人工操作保持初筛结论与证据。
5. 运行绑定业务快照、配置版本及完整结果。新版本发布、业务导入和复核不改写历史初筛结果。
6. 支持风险列表筛选、详情证据、人工研判、图谱邻域与最短路径、CSV/JSON/可打印 HTML 报告、操作审计和 API 工具说明。
7. 默认使用虚构业务数据，离线运行，无外部模型调用。演示规则不是采购人制度；统计结果不是招标指标实测结果。

## 数据与安全

Python 3.10+ 标准库 + SQLite + 原生 HTML/CSS/JS；默认绑定 127.0.0.1:8765。校验 Host、Origin、内容类型和自定义请求头，限制请求大小，不提供文件路径读写接口。演示为本机单用户，操作人姓名不是身份认证，不声称具备生产 RBAC、等保、加密存储或真实图数据库。

## 验收

使用 unittest 覆盖：三维/单维/零维、样本不足、权重、配置验证、不兼容本体发布、快照隔离、并发修订冲突、持久化、人工研判、CSV 公式防护、API Host/Origin/路径/载荷安全；浏览器验证配置→发布→筛查→研判→导出。
