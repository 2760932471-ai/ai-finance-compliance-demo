# 风险模型与评测

位置：运营中心 → 风险模型与评测。审核中心的“交叉核验策略”是原规则组合配置，统计模型在此独立管理。

## 三类内置模型

| 模板 | 计算方法 | 配置 |
|---|---|---|
| 采购单价异常 | 同类历史中位数/MAD或分位数区间 | 指标、分组、历史窗口、最少样本、灵敏度/分位点 |
| 月度费用异常增长 | 按分组及月份汇总金额，比较历史月度区间并计算同比、环比 | 分组、历史窗口、最少月份、季节选项 |
| 多指标付款行为异常 | scikit-learn Isolation Forest，100棵树，随机种子42，按历史稳健尺度标准化 | 至少2项指标、至少20条历史样本、训练尾部分位比例 |

MAD 尺度为 max(1.4826 × MAD, abs(中位数) × 1%, 0.000001)，防止历史数据恒定时除零。单价单位由导入数据口径决定，必须保证同类可比，不能混入不同币种、税口径和计量单位。当前不自动换算。

历史窗口严格早于待评估月，当前月和未来数据不进入训练、阈值计算。季节选项仅保留历年同月份，不自动拟合季节模型；窗口不足时明确未评估。机器学习阈值采用历史训练异常得分的指定尾部分位，不代表经业务标定的风险概率。单指标区间仅提供核查参考，不宣称为模型因果归因。

## 数据和评测

- 独立历史数据集；默认1440条、30个月虚构记录（2024-05至2026-10），人工植入2026-07和2026-10共4条高单价样本。标签是合成真值，不是真实核查结论。
- 导入 JSON 数组，最多5000条且文件需小于1.9MB；导入覆盖当前历史数据，既有评测快照保留。格式参见 examples/historical-data.json。
- 必填 id/date/unit/business_type/item/supplier/amount/quantity/payment_days；日期 YYYY-MM-DD；金额非负；数量至少0.000001；付款天数非负；label 可为 true/false/null。单价由金额除数量派生。
- 支持单月评测和连续最多12个月向前回测，每个月独立使用之前的历史。数据缺月不补零，同期无记录显示空样本。
- 无标签样本不纳入混淆矩阵；无正类或无预测正类时召回率/精确率显示“—”。样本不足不算正常或命中。
- 月度样本标签：月内任一记录为异常则标记异常；全部记录标记正常才标记正常，否则未标注。该口径需要真实业务验证。
- 人工标签仅用于该评测的效果统计，不参与训练、不改正式审核结论。核实人、依据和历史保留；汇总指标可使用人工标签，逐月表保留原始标签指标。
- 保存草稿后发布才生效。每次评测保存已发布模型、算法版本、数据快照与摘要。后续导入和发布不改旧结果。人工标签独立追加，原始评测结果不覆盖。

## 工程边界

统计异常仅为第二维线索，当前模块不自动回写原三维评分；原风险研判中的横向规则仍使用其原有工作数据与实现。生产融合须统一业务主键、证据关联和评分口径。当前支持本机小规模演示，不包含分布式训练、自动调参、在线漂移监控或生产效果承诺。

“审核回归评测”复用原审核反馈和预期结论比较功能，属于软件行为回归测试，与统计回归算法无关。
