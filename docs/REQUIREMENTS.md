# 招标要求与演示实现对应

本表是软件演示范围说明，不是无偏离承诺或生产验收报告。

| 条款 | 本版实际可演示 | 未完成/后续接入 |
|---|---|---|

| 1.3 财务本体 | 四层实体/属性、关系、分类、映射配置；版本与影响分析；JSON导入导出 | 图数据库实例；新增语义关系的自动抽取与实例化；覆盖全类业务 |
| 1.4 流程核验 | 合同超付、验收缺失、签约付款时序 | 全业务链路、内控与法律规则库 |
| 1.4 横向对比 | 可配置分组的 MAD/分位区间、月度滚动基线与同比环比、多指标 Isolation Forest、逐月回测和核实标签 | 真实专家标注与查实率实测；新统计评测尚未自动回写三维评分 |
| 1.4 图谱联查 | 共用账户、两跳邻域、最短路径、度中心性 | 社区发现、图数据库、大规模图计算 |

| 2.4 可扩展 | 既有规则的阈值/权重/启停、实体属性分类可配置 | 新算法、新数据形态与图谱实例关系需开发适配 |

### 评分演示口径

展示可操作流程、输入与输出、配置变化前后的计算差异，以及清楚的工程边界。不要把虚构数据上的命中数量叫做“查实率”；不要将125项代码测试解释为生产性能、全业务覆盖或招标验收通过。
